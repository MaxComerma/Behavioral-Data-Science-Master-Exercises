# Behavioral Data Science — Master Exercises

Practical coursework and projects from the MSc in Behavioral Data Science at IL3–Universitat de Barcelona.

The repository covers data management, statistical modelling, psychometrics, machine learning, deep learning, data visualization and reproducibility, with an emphasis on applying data science methods to human behavior.

> **Language:** Most of the original coursework is in Spanish. Some notebooks and project materials contain English sections or translated versions.
